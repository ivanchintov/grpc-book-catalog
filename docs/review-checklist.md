# Pull Request Review Checklist

## Design

- Is the solution simple?
- Are responsibilities well separated?
- Does it follow the project's architecture?

## Code Quality

- Clear naming
- No duplicated logic
- Appropriate abstractions

## Testing

- Unit tests added where appropriate
- Existing tests still pass
- Edge cases considered

## API

- Backward compatible?
- Correct status codes?
- Proper validation?

## Documentation

- README updated if necessary
- API design updated if necessary
- Engineering Journal updated

## Build

- Project builds successfully
- Static analysis passes
- Formatting passes
