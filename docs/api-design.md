# Book Catalog API

## Purpose

The Book Catalog service provides a simple API for managing a collection of books.

The primary goal of this project is educational. The service is intentionally designed to demonstrate gRPC concepts such
as Protocol Buffers, unary RPCs, streaming, error handling, metadata, authentication, and API evolution while following
good software engineering practices.

The service is responsible for storing, retrieving, searching, listing, and deleting books.

---

## Entity

### Book

| Field            | Description                               |
|------------------|-------------------------------------------|
| id               | Unique identifier generated by the server |
| title            | Title of the book                         |
| author           | Name of the author                        |
| isbn             | International Standard Book Number        |
| publication_year | Year the book was published               |
| genre            | Literary genre of the book                |

### Design Decisions

* The server is responsible for generating book identifiers.
* ISBN is expected to uniquely identify a published book.
* Clients do not provide the `id` when creating a new book.
* The API uses Protocol Buffers as the service contract.

---

## Operations

### AddBook

Creates a new book in the catalog.

**Request**

* AddBookRequest

**Response**

* Book

#### Validation

| Condition                       | gRPC Status        | Description                                                           |
|---------------------------------|--------------------|-----------------------------------------------------------------------|
| Required field is empty         | `INVALID_ARGUMENT` | The field cannot be empty.                                            |
| Field contains an invalid value | `INVALID_ARGUMENT` | The field contains an invalid value, such as an invalid year or ISBN. |
| ISBN already exists             | `ALREADY_EXISTS`   | A book with the specified ISBN already exists.                        |

---

### GetBook

Retrieves a single book by its identifier.

**Request**

* GetBookRequest

**Response**

* Book

---

### ListBooks

Returns all books currently stored in the catalog.

**Request**

* ListBooksRequest

**Response**

* ListBooksResponse

---

### DeleteBook

Deletes a book from the catalog.

**Request**

* DeleteBookRequest

**Response**

* Empty

---

### SearchBooks

Searches for books matching one or more search criteria.

**Request**

* SearchBooksRequest

**Response**

* SearchBooksResponse

## Request Messages

### AddBookRequest

Request message used to create a new book.

| Field            | Type   | Description                                                                          |
|------------------|--------|--------------------------------------------------------------------------------------|
| title            | string | Title of the book. Required and must contain one or more non-whitespace characters.  |
| author           | string | Name of the author. Required and must contain one or more non-whitespace characters. |
| isbn             | string | ISBN of the book. Required, must be valid, and must be unique within the catalog.    |
| publication_year | int32  | Year the book was published. Required and must represent a valid publication year.   |
| genre            | Genre  | Genre of the book. Required and must be a valid value from the `Genre` enum.         |

The `id` is intentionally not included because it is generated by the server.

---

### GetBookRequest

Request message used to retrieve a book by its identifier.

| Field | Type  | Description                                |
|-------|-------|--------------------------------------------|
| id    | int64 | Unique identifier of the book to retrieve. |
